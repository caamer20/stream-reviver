# Support

Before requesting help, run `npm run verify`, reproduce on the local fixture, and export diagnostics from the settings page if safe to do so. Diagnostic exports may contain page URLs and selectors; redact them before sharing.

Include the extension version/channel, Chrome or Firefox version, operating system, fixture/site behavior, relevant settings, and exact observed status. Do not share credentials, private stream URLs, cookies, DRM information, or account data.

Browser security policies, inaccessible cross-origin frames, DRM internals, and site controls can limit recovery. Those limitations are expected and are not bypassed.
