# Security policy

## Supported version

Security fixes target the latest released minor version. Pre-release development and beta builds receive fixes on a best-effort basis and should not be used as the stable release.

## Reporting

Do not publish exploit details or sensitive URLs in a normal issue. Use GitHub's private vulnerability reporting/security-advisory feature on the repository. Include the affected version, browser, reproduction steps, expected impact, and whether a malicious page or user interaction is required.

No bug bounty is currently offered. Good-faith reports will be acknowledged and assessed before disclosure. See [docs/SECURITY.md](docs/SECURITY.md) for the threat model and controls.
