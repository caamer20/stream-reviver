# Privacy policy

Effective: 2026-08-29

Stream Reviver has no analytics, advertising, tracking, telemetry endpoint, or external API. Extension code does not sell, share, or transmit user data.

## Data processed locally

- Synced extension storage: global settings and per-site origins, selectors, URL rules, and recovery preferences.
- Local extension storage: disclaimer/privacy acknowledgements, bounded diagnostic history, player preferences, declarative profiles, and locally learned recovery outcomes.
- Session extension storage: current status, reload/circuit limits, expiring restoration snapshots, and session-visit markers when the browser supports it.
- Optional visual watchdog: a crop of the active visible tab is reduced immediately to an 8×8 comparison pattern in memory. Neither screenshot nor pattern is stored or transmitted.
- Optional advanced bridge: aggregate player/library states and counters only. It does not read media bytes, keys, credentials, WebRTC candidates, SDP, IP addresses, or content.

Users choose each site origin and approve the browser permission prompt. Disabling a site unregisters scripts and requests removal of that origin permission. The settings page can delete history, models, preferences, profiles, session state, or all extension data. Import never grants site access.

Settings sync, when enabled by the browser, is operated by the browser vendor under the user's browser account and policies. Stream Reviver has no independent access to that service.

The extension does not bypass DRM, CAPTCHAs, paywalls, authentication, anti-bot controls, or site terms. This policy must be published at a stable HTTPS URL before store submission.
