Enable visual monitoring?

The visual watchdog can capture the elected player in the active visible top-level tab. Processing stays in this browser: the privileged extension background crops and reduces the image to a fixed 64-bit comparison hash, immediately discards the capture, and returns no image bytes to page-facing code. The hash is not stored or sent externally. Static video frames can be legitimate, so visual evidence never triggers recovery by itself.
